Hey there! As you can probably see, I am not really what you'd call a web developer. I prefer things that run in the command line -- but I wanted this to be accessible from my 3ds, laptop, and phone, so a webapp was the best choice. There is not and never will be any syncing of data to the server, as I ahve no interest in maintaining anything that requires security/privacy protocols. Instead, data is saved on your machine using cookies (which are not used for any purpose other than to let you save settings and tasks). You are advised to back up cookies to prevent data loss. Data syncing between devices will only be possible by sharing your cookie file between said devices.

This is a collection of tools that I'm building to help organize my Crystal Clear playthrough. Planned features are laid out in the issue tracker. Existing features include: Nothing! D:

Since I'm doing this for free in my spare time, and it's not really a priority, you shouldn't expect fast development. However, if you'd like to submit a pull request to add new features, fix bugs, or anything else, then please do so, and I will take a look!
